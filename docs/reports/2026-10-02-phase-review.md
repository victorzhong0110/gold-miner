- R1：配置/切换模型后不被 rules 缓存拦住；模型失败后下一次请求可恢复。模型缓存绑定配置修订号，导入缓存不冒充本机配置已验证。
- R2：请求中取消触发 AbortController，取消为终态；迟到搜索/模型回调不继续检索、不恢复 UI、不写成功缓存。关闭或离开页面会取消任务，重复导航事件不重发。
- R3：校验 owner/repo，导入和显示均重建 `https://github.com/<owner>/<repo>`；不信任外来 html_url。
- 受信存储隔离为共享初始化承诺，避免并发首次请求竞态；页面不能修改设置、导入/导出或清空本地数据；取消按发送者 tab 隔离。
- 探索余量实际选择另一来源，topics/描述/兴趣与双语获取可用；规则排序不设 stars 排除线。
- 同时最多两个任务，每任务最多四次 GitHub 调用；SEARCH 额外最多一次模型调用。限流依据响应进入退避，无自动重试风暴。发送计数与缓存命中单列，未知费用/tokens 不填猜测。
