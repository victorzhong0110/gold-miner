# E9 术语表（未验证）

本目录为拟补充实验 E9 用的小型开源软件用途术语表，独立编写，未从 EhTagTranslator 或 EhViewer 词库复制任何词条。

- 词表用于生成查询，不是仓库白名单：有词条、无规范 topics、无共享译文的仓库，仍保留发现路径，仍需走真实候选、README 检查与去重核对。
- E9 分三组：A 纯词表（只用本地映射，不调用模型，未覆盖则明确记录）、B 纯 AI（同一模型加固定提示词，不用词表）、C 混合（先查词表，未覆盖或有歧义时再调用同一模型补充）。
- 本文件未验证准确率：`terms.yaml` 中的中英文映射只是待验证的候选表达，不是结论，不能当作同义保证使用。

文件：

- `terms.yaml`：40 条概念，每条含稳定 `id`、中文表达 `zh`、英文表达 `en`、一句 `notes`。
- `notes` 只写“相关但不是同义”的陷阱区分，不写准确率结论。
