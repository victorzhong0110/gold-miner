# 0001 项目名称与可发现性

更新：2026-09-17。
状态：沿用发起人已选择的工作名“黄金矿工 / Gold Miner”；改名保留为后续选项，不阻塞实验。

## 依据

发起人已明确选择该名称，认为容易理解。首次 [E8 探测](../../experiments/E8-discoverability/2026-09-17-probe.md)记录了同名项目与游戏竞争，但当时本仓库简介和 topics 为空，创建时间也很短，普通搜索引擎尚未检查。

因此可以认定有辨识度风险，不能由这次探测断言“名称加用途必败”，也不能由用途查询零结果断言市场空白。旧评审中的不同建议保留在[原记录](../reviews/2026-09-17-v0.3-review.md)中。

## 当前安排

1. 使用现有名称，完善双语用途信息和语言入口。
2. 应用仓库简介/topics 后，分别复测 API、网页和外部搜索。
3. 检查名称加用途能否定位官方入口；裸词未排名第一不是自动改名条件。
4. 若完成基础信息后仍有明显混淆，再比较副标题、英文标识或改名；记录新的证据与维护成本。

项目自身可发现性的目标保持不变。具体实施见 [v0.4 的 W7/W14](../plan/v0.4.md)。
