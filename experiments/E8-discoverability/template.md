# E8 探测记录模板

复制为 `YYYY-MM-DD-probe.md`。对应 v0.3 第 11 节；每次改名称、简介、topics 或新增介绍语言后跑一次。

## 条件

- 日期与时区
- 仓库当时状态：名称、简介、topics、许可证、README 语言版本
- 入口：分别记录 GitHub REST Search API、GitHub 网页搜索（登录／未登录）、普通搜索引擎（名称、语言界面、地区）
- 检查范围：前 N 名（首轮统一前 20）

## 查询

每种支持语言两类，各写在两组里。站内组去掉"GitHub"一词（站内搜索把它当普通词项，见 [2026-09-17 记录](2026-09-17-probe.md)）；站外组保留。

- 站内·名称加用途：`{中文名}`、`{English name}`、`{中文名} {用途词}`、`{English name} {purpose words}`
- 站内·用途词：`跨语言 项目发现`、`cross-language project discovery`、`{使用者自然表达}`
- 站外·名称加用途：`{中文名} GitHub`、`{English name} GitHub`
- 站外·用途词：`GitHub 跨语言搜索`、`GitHub cross-language discovery`、`{使用者自然表达}`

用途词样例应随实际使用者的表达补充；补充的词记录来源。

## 每条查询记录

- 查询原文、语言、入口
- 结果总数、前 5 名（仓库与 stars）
- 本仓库是否出现、名次；未出现写"未找到"
- 备注：同名干扰项、排序异常

## 解读

- 名称加用途是否找到官方入口（第 11 节验收）
- 用途词找到比例与遗漏原因
- 与上一次记录的差异

## 未检查

写明本次没有覆盖的入口、地区、登录状态与原因。未收录或查不到仍是未通过，不以仓库内搜索或直接网址证明可发现。

## 复现

贴出实际使用的命令或操作步骤，含配额与间隔。
