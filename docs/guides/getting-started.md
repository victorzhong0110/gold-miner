# 10 分钟上手（中文 / English）

试验扩展，**不是**已验证的产品效果。无需发起人 API 也能加载界面。

## 中文

1. 克隆本仓库，或解压 `dist/gold-miner-extension-0.1.0.zip`。
2. Chrome 打开 `chrome://extensions`，打开「开发者模式」。
3. 「加载已解压的扩展程序」，选仓库里的 `extension/` 目录（或解压后的 `gold-miner-extension/`）。
4. 打开 https://github.com/search?q=clipboard+history 或任意仓库页。
5. 页面上方应出现「跨语言候选」或「继续探索」。可点感兴趣 / 不相关 / 见过。
6. 右上角扩展「详细信息 → 扩展程序选项」：阅读语言、兴趣、可选 BYOK。
7. 不填 API key：只用规则扩展 + 公开 GitHub 搜索（配额紧张时会看到限流）。
8. 要停个性化：设置里取消勾选，或「清除本地数据」。
9. 导出缓存不含密钥；不要分享含私有仓库笔记的自制文件。
10. 遇到卡住：点取消。已发出的模型请求可能已计费（未配置模型则不会）。

真机逐步操作若未做，报告写「未运行」。

## English

1. Clone the repo or unzip `dist/gold-miner-extension-0.1.0.zip`.
2. Chrome → `chrome://extensions` → Developer mode.
3. Load unpacked → choose `extension/` (or the unzipped folder).
4. Open a GitHub search or repository page.
5. A panel lists a few candidates with purpose, source, why, and a link.
6. Options: reading language, interests, optional BYOK.
7. Without a key, only rule expansions + public search run.
8. Disable personalization or clear local data anytime.
9. Cache export strips secrets and private notes.
10. Cancel stops new work; in-flight paid calls may still bill.

This does **not** prove E1/E2/E4 success.
